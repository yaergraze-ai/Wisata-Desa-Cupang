# Kode diagram Wisata Desa Cupang
Enam file .mmd merupakan kode Mermaid yang dapat ditempel ke diagrams.net/draw.io.

1. Buka https://app.diagrams.net/.
2. Buat diagram baru.
3. Pilih menu **Arrange > Insert > Advanced > Mermaid** (lokasi menu dapat sedikit berbeda menurut versi).
4. Salin **seluruh** isi salah satu file .mmd, tempel di kotak Mermaid, lalu klik **Insert**.
5. Atur tata letak. Simpan lewat **File > Save As** untuk menghasilkan file .drawio, atau **File > Export as > SVG/PNG** untuk dimasukkan ke Word.

Catatan: kode 02 merender visual setara peta use case menggunakan flowchart, bukan notasi aktor dan elips UML standar sepenuhnya. Untuk diagram use case formal, ganti bentuknya di draw.io atau susun ulang dengan PlantUML. Kode 05 Class Diagram dan 06 ERD memakai notasi Mermaid yang sesuai kategori.

Diagram merupakan rancangan konseptual project, bukan hasil sistem yang sudah diuji.
